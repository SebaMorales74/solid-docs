# Overview

<Callout title="Prerequisites">
	La documentación está basada en la última versión de Solid Router.
	Para útilizar esta versión, necesitas tener instalado Solid v1.8.4 o versiones más recientes.
</Callout>

Solid Router es el enrutador universal para Solid, el cuál funciona para ser renderizado en el cliente o en el servidor.
Está inspirado através de combinar los paradigmas de [React Router](https://reactrouter.com/en/main) y de [Ember Router](https://guides.emberjs.com/release/routing/).

Un enrutador proporciona una forma de cambiar la vista del usuario basado en la URL del navegador web.
Esto permite una aplicación de "una sola página" para simular un sitio tradicional de múltiples páginas.
Para útilizar Solid Router, los componentes son llamados Rutas que dependen del valor de la URL (la "ruta") especificada, y el enrutador maneja el mecanismo de ir intercambiando cada una.
